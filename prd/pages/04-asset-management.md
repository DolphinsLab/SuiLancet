# Asset Management（资产管理）

> 路由：`/manage`
> 模块：Web / Object 转移与钱包迁移
> 前置条件：连接钱包；每笔写操作需要钱包签名

## 页面目标

提供常用的批量 Object 转移，以及将当前钱包的 Coin、NFT 和其他 Object 迁移到新地址的流程。

## 功能一：Batch Transfer

### 字段

| 字段 | 类型 | 必填 | 校验 |
|---|---|:---:|---|
| Recipient address | 文本 | 是 | 仅校验非空 |
| Object IDs | 多行文本 | 是 | 每行一个 ID；去除空行 |

### 交互

- 点击“Transfer Objects”后，把所有输入 ID 构造成一笔 `transferObjects` 交易。
- 成功时显示转移数量和缩略交易摘要，并清空 Object ID 输入。
- 失败时保留输入并显示错误。
- 页面不自动分批；输入过多时可能超过交易大小或参数限制。

## 功能二：Wallet Migration

### 字段与警告

| 字段 | 类型 | 必填 | 说明 |
|---|---|:---:|---|
| Target address | 文本 | 是 | 仅校验非空；页面强调将转移全部资产 |

### 执行流程

1. 扫描钱包全部 Coin Object。
2. 扫描钱包全部非 Coin Owned Object。
3. 将非 SUI Coin 每 50 个一批转移。
4. 将其他 Object 每 50 个一批转移。
5. 最后合并可用 SUI 并把 `tx.gas` 转给目标地址，以便前序批次保留 Gas。
6. 每批成功后继续下一批，全部完成后展示成功状态。

页面会实时显示扫描结果、当前阶段和批次信息。任一批报错会中断后续流程并显示错误；已成功提交的前序批次不会自动回滚。

## 业务规则与限制

- Web 迁移没有预览模式、资产类型筛选、排除列表或可配置批大小；这些只在 CLI/SDK 中提供。
- 迁移会尝试转移所有非 Coin Owned Object，包括可能不可转移或承担权限角色的对象，因此可能在某批失败。
- 页面没有目标地址格式校验或二次确认。
- 批量流程会连续触发钱包签名请求，用户拒绝任一请求会中断流程。
- 页面没有 Kiosk 专用迁移逻辑，也不会先从 Kiosk 中取出托管物品。
- 页面没有失败对象清单或断点续传；重新执行前应先重新扫描资产状态。

## 页面关系

- 入口：侧边栏 Manage。
- 数据依赖：Sui gRPC Owned Object 查询。
- 写入依赖：浏览器钱包签名执行。
